# Inventory Tracker Instructions

## How to Run the Script

1. **Prerequisites**
   - Make sure you have Python installed on your machine.
   - Install the required packages by running:
     ```bash
     pip install -r requirements.txt
     ```

2. **Running the Script**
   - Navigate to the directory where the `inventory_tracker.py` file is located.
   - Run the script using the following command:
     ```bash
     python inventory_tracker.py
     ```

3. **Configuration**
   - Ensure that the configuration file is set up correctly before running the script. 
   - Refer to the `config_example.json` file for guidance on the configuration format.

## Notes
- Ensure you have the necessary permissions and dependencies set up.
